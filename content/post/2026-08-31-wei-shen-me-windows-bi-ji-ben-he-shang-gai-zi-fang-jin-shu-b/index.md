下班或者下课的时候，把笔记本盖子一合，塞进双肩包。坐了半小时地铁回到家，拉开拉链伸手去拿，手刚碰到机身，指尖就被烫得下意识缩了回来。

整台电脑滚烫，散热风扇在黑漆漆的书包里还在呼呼狂转。掀开盖子一看，出门前满电，现在只剩 2% 见红了。

很多人第一反应都是自我怀疑，以为是自己刚才忘了点睡眠，或者是包里的水杯、钥匙压到了开机键。

其实不是你的问题。这是微软过去几年为了死磕所谓**「现代待机」**，给全球 Windows 用户留下的一个大坑。

在以前的 Windows 时代，电脑休眠用的是一套运行了二十多年的技术规范，叫 **ACPI S3 睡眠**。这套机制很简单，只要你把笔记本盖子合上，系统就会切断 CPU、显卡、风扇和绝大部分主板电路的供电，只给内存保留一点微弱电流用来维持工作现场。

那会儿的电脑合盖是**真断电**。整机功耗通常不到 0.5 瓦，哪怕在包里放上三天，拿出来也是冰凉的。

后来微软看着 iPad 和 MacBook 眼红。

苹果的笔记本掀开盖子能像手机一样秒开，合盖息屏的时候还能在后台收邮件、下文件、放音乐。微软也想让 Windows 电脑拥有这种体验，于是在 Windows 10 里强推、并在现在的 Windows 11 上彻底普及了一套叫 **Modern Standby（现代待机，代号 S0ix）**的机制。

这套机制的核心，就是合盖之后 CPU **坚决不断电**。它只是进入一种低功耗模式，WiFi 照样连着，后台服务和系统更新照样跑。

![](https://xiaobox-public-images.oss-cn-beijing.aliyuncs.com/images/windows-tieban-S3%E5%AF%B9%E6%AF%94S0ix.png)

但苹果能这么干，是因为苹果的芯片、硬件和系统全是自己封闭研发的。Windows 面临的是一个庞杂的硬件生态，每台电脑里都塞满了第三方的声卡驱动、网卡驱动、指纹模块、外接拓展坞，后台还跑着各种软件和游戏反作弊程序。

在现代待机的规则下，只要这堆驱动里有一个没能正常进入低功耗状态，或者包里的蓝牙鼠标晃动了一下连上电脑，CPU 就会瞬间被叫醒，直接进入全功率运转。

双肩包本身就是隔热的海绵和尼龙，进风口和出风口全被堵死。十几瓦的发热在密闭空间里散不出去，半小时就能把机身闷到七八十度。风扇在里面拼命抽风，抽的全是死循环的热空气，直到把电池彻底榨干。

![](https://xiaobox-public-images.oss-cn-beijing.aliyuncs.com/images/windows-tieban-%E4%B9%A6%E5%8C%85%E7%83%AD%E5%BE%AA%E7%8E%AF%E5%89%96%E9%9D%A2.png)

2022 年科技博主 Linus 拿多台 Windows 11 笔记本做实测时，还抓到了一个更离谱的 Bug。

如果你先合上笔记本盖子，然后再拔掉电源线塞进包里，Windows 会把「断开电源」识别为一个电源状态切换事件，直接把系统叫醒。但因为盖子早就合上了，系统不会再触发第二次睡眠，电脑就这么在你的包里满负荷烤了一路。

当年很多玩家受不了，通过修改注册表把 `CsEnabled` 改成 `0`，强行退回传统的 S3 睡眠。

到了 Windows 10 2004 版本，微软直接在系统里删掉了这个注册表键值。后来大家又发现可以改 `PlatformAoAcOverride`，微软干脆拉着各大 PC 厂商，直接在所有出厂预装 Windows 11 的新款笔记本 BIOS 固件里，把 S3 睡眠的代码彻底剔除了。

宁可让用户在背包里烤电脑，也要保住这套现代待机。

![](https://xiaobox-public-images.oss-cn-beijing.aliyuncs.com/images/windows-tieban-S3%E4%B9%8B%E9%97%A8%E8%A2%AB%E7%A0%8C%E6%AD%BB.png)

想看自己的电脑有没有中招很简单。不管是 Windows 10 还是最新的 Windows 11，按 `Win + R` 打开运行窗口，输入 `cmd`，敲一行命令，

```bash
powercfg /a
```

如果屏幕上显示 `待机 (S0 低电量待机) 已启用`，而下面写着 `待机 (S3) 系统固件不支持`，就说明这台电脑在硬件层面已经被剥夺了真正睡觉的能力。

还可以敲另一行诊断命令，

```bash
powercfg /sleepstudy
```

它会生成一份详细的 HTML 报告，用红色的时间轴列出过去几天里，电脑在合盖状态下到底被哪个驱动唤醒过、掉了多少电。

在微软彻底解决这套机制之前，防烤机最直接的办法只有一个。

进控制面板的电源选项，把「关闭盖子时的操作」，从默认的「睡眠」改成**「休眠」（Hibernate）**。

休眠虽然开机时需要多读条三秒，但它是把内存数据直接写进硬盘，然后彻底断电关机。

在所有系统都在教你「随时在线」的时候，能踏踏实实断电关机，比什么无缝唤醒都实在。
