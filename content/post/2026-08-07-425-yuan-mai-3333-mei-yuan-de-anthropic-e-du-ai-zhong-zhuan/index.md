我在上家做 AI FinOps，每天盯着 API 账单，花了大半年把商业模型的月成本从 200 万砍到 120 万。那段经历让我对 API 定价特别敏感，所以看到今年 6 月 Matt Lenhard 在 Vectoral 上发的这篇中转站市场调查，第一反应是拆价格。

Lenhard 是前 AI 实验室的网关工程师，花了几个月追踪中国的 AI API 中转站市场，最后画出一幅完整的产业链地图。文章上了 Hacker News 首页，130 个赞，77 条讨论，吵得最凶的问题是，这到底算诈骗还是套利。

先看价格。他找到的最便宜的中转站叫 Now Coding，425 元人民币买到相当于 3333 美元的 Anthropic 官方额度。每花 1 美元实际只付 0.13 美元，折扣率 97.8%。十家中转站排名，最低折扣也有 94.1%。

我砍过 40% 的 API 成本，已经算大动作了。97.8% 的折扣率，这不是靠谈判或者技术优化能拿到的，钱一定从别的地方来。

Lenhard 把供应链拆成四层。最底下是商人（merchant），负责弄到 API key。他列了五种主要手段。

第一种是批量薅免费试用。写脚本自动注册账号，领到免费额度就灌进代理池。AI 厂商为了降低注册门槛不得不把首次体验做得简单，这正好给了批量注册空间。

第二种是拒付攻击。用信用卡正常消费一段时间的 API，等账单出来以后向银行发起拒付。厂商已经提供了算力，钱被银行追回了。

第三种是预付卡套利。低面值预付卡绑定账号，消费超出卡内金额后弃卡。

第四种叫 open inference hijacking。有些公司的客服机器人或者内部 demo 接了大模型 API，但没做好鉴权。中转站找到这些暴露的端点，把流量灌过去，消耗的是别人的账单。做过 API 网关的都知道，暴露在公网的端点如果只靠前端校验，迟早会被扫到。

第五种是 denial-of-wallet 攻击。大量并发请求打到目标账号上，纯粹烧掉别人的额度。

拿到 key 以后，第二层是中转站运营者。他们用代理软件把多个 key 汇聚到一个网关后面，对外提供 OpenAI 兼容格式的 API 端点。买家拿到一个地址和一个 token，背后是一整个被盗用的 key 池。

第三层是分销商，负责获客和收款。第四层是终端买家，开发者或小团队居多。

规模已经很大了。十家流量最大的中转站，合计月访问量 360 万次。市场成熟到有了价格比较网站、分销返佣体系，甚至有中转站每天搞 API key 抽奖。

技术上支撑这一切的几乎全是开源软件。核心项目叫 one-api，是一个 OpenAI 兼容的 API 网关，设计用来在多个模型供应商之间做负载均衡和 key 管理。它有一个更活跃的 fork 叫 new-api，加上了自助支付。两个项目都在 GitHub 上公开。工具本身合法，同一套架构正经用是 API 网关，歪着用就是中转站的基础设施。

谁在买？Lenhard 画了三类。第一类是想省钱的开发者，API 官方定价对个人项目确实不便宜。第二类是受地理限制的用户，OpenAI 和 Anthropic 的 API 在大陆不直接可用，中转站提供了绕过限制的通道。第三类让厂商最头疼，做模型蒸馏的团队。大量调用闭源模型生成训练数据来训练自己的小模型，中转站的价格让这件事变得划算。

Hacker News 上的讨论值得看。jonfromsf 指出，很多中转站的手法根本没涉及偷信用卡，就是把订阅计划的额度用满再转售，算违规但不算盗窃。tancop 分得更细，用假信用卡的确实是欺诈，批量薅试用是灰色地带，但如果有人正常付费买了订阅再把额度转卖，道德上他觉得没什么问题，即使违反了服务条款。

这三种情况混在同一个市场里，很难一刀切。

厂商不会自己消化损失。每一笔拒付、每一张被盗用的信用卡、每一次被薅的免费试用，最终都会计入 API 的定价。正规付费的开发者在为这些欺诈买单。我做 API 成本管理那段时间有个体感，API 价格里有多少是纯算力成本，有多少是风控和坏账分摊，外面的人很难看到。中转站市场把坏账这一层放大了，正规用户承担的隐性成本也跟着涨。

Lenhard 建议厂商在注册环节增加摩擦、做行为异常检测、关联账号聚类、消费上限、可疑流量静默限速。Anthropic 和 OpenAI 已经在收紧免费层，反滥用检测也更激进了。但只要定价差和访问限制还在，中转站就会继续长出来。一边是高价，一边是需求，中间商一定会出现。

V2EX 上有个帖子叫"AI 中转站黑话大全"，3.5 万次浏览，190 条回复。这在中文技术社区已经是公开话题了。
